# Стековая машина

Программа для вычисления математических выражений в постфиксной (обратной польской) нотации с пошаговой визуализацией состояния стека.

---


## Принцип работы и операторы

- **Арифметические операции:** `+`, `-`, `*`, `/` (деление проверяет деление на 0).
- **Специальный оператор `~`:**
  - Если оба операнда не равны 0: вычисляет модуль разности $|x - y|$.
  - Если хотя бы один из операндов равен 0: вычисляет сумму всех значений в текущем стеке (включая извлеченные операнды), возводит её в квадрат, очищает стек и помещает результат в стек.
- Операнды и операции разделяются пробелами.

---

## 1. Установка и настройка окружения

Проект использует менеджер пакетов **uv**.

Чтобы создать виртуальное окружение и установить все зависимости:

```bash
uv sync
```

---

## 2. Запуск программы

Скрипт принимает выражение через аргумент командной строки в кавычках:

```bash
python src/main.py "3 0 4 ~ 2 ~"
```

> Альтернативный вариант:
> ```bash
> uv run src/main.py "3 0 4 ~ 2 ~"
> ```

### Примеры вывода:

1. **Пример использования:**
   ```bash
   python src/main.py "3 0 4 ~ 2 ~"
   ```
   *Вывод в консоль:*
   ```text
   Стек: [3.0]
   Стек: [3.0, 0.0]
   Стек: [3.0, 0.0, 4.0]
   Стек: [49.0]
   Стек: [49.0, 2.0]
   Стек: [47.0]
   3 0 4 ~ 2 ~ = 47
   ```

2. **Заботливая обработка ошибок:**
   Если запустить без аргументов:
   ```bash
   python src/main.py
   ```
   *Вывод:*
   ```text
   Ошибка: пожалуйста, введите выражение в кавычках
   ```
